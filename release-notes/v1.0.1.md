`r5studiomdl` 1.0.1 fixes authored additive animations and adds in-game evidence for node transitions.

**Fix: authored `subtract` clips**
- A sequence whose clips are all deltas now gets sequence flags 0x4 | 0x10 (delta, post), as all 416 such retail S3 sequence assets have.
- Without them, R5R played an authored `subtract` clip as a whole pose: used as an autolayer, it replaced the base pose instead of adding to it.
- In game, a base pose with the additive clip layered on it now poses like the full clip, within 0.0035 in (`tools/build_r5r_delta_test.py`).
- Imported and decompiled retail sequences already kept their stored flags and are unchanged.

**New: node transitions checked in game**
- `ingame54.py --weapon-actions` starts weapon activities and logs the viewmodel's sequence every frame.
- The Mastiff with its rebuilt viewmodel played the same sequences as the retail one, at the same times. That includes the `switch_to_twohanded` transitions R5R takes from the rig's transition table when a one-handed sequence returns to a two-handed one.

**Validation for this source**
- Compiler `99bffdab…`.
- The S0-S3 corpus round trip and the S3 sequence-import check give the same results as v1.0.0. The in-game Mastiff build is byte-identical.
- 92 Python regressions and both CTest groups pass.
