First release of `r5studiomdl`, a native Apex Legends / R5Reloaded model compiler for QC, SMD and DMX sources. It writes MDL v54 render models, VG and PHY data, BVH collision, rigs and sequence assets for the early-season profiles S0-S3. The release also includes a Python v54 decompiler, an importer for retail animations, an RPak packaging wrapper and validation tools. It is part of a family with [r1-model-compiler](https://github.com/taskinoz/r1-model-compiler) (Titanfall 1, MDL v52) and [r2-model-compiler](https://github.com/taskinoz/r2-model-compiler) (Titanfall 2, MDL v53).

This release targets Season 3 retail compatibility. The corpus, import and in-game results below were measured with a local build of this source, SHA-256 `537608027fd8c106796d0dba3c07b685672b3dbba117d499004c1f0f8fad3786`. The executable in the ZIP was built from the same commit by the release workflow on GitHub's runner, so its hash differs. That build passed the regressions and package check below.

**Models**

- All 581 installed S3 models decompile, recompile and match retail in every compared field: geometry, skinning, materials and skins, bones, attachments, hitboxes, physics, BVH collision and every header field.
- All 354 S3 models with physics also match.
- The only remaining difference is float rounding in the bones' pose-to-bone matrices.
- In S0-S2, every model rebuilds except tablet_mini, whose retail data fails the reader's checks.

**Animations**

- 4,248 of 4,249 retail S3 sequence assets import into an editable QC include, rebuild and match retail in every compared field and every decoded frame. The comparison covers events, IK rules, autolayers, transition nodes, blends, frame movement and additive clips.
- Every rebuilt rig matches retail's: its header counts, node names and transitions.
- The remaining sequence belongs to a grunt rig that S3 does not ship.

**In game (R5Reloaded)**

- All 57 sequences of the Mastiff viewmodel's rig were imported onto the decompiled viewmodel and posed beside the installed retail viewmodel. The 3,420 attachment samples match within 0.0071 in and 0.019 deg. They cover autolayers, transition nodes, additive clips, blends and IK rules.
- An imported drone matches exactly.
- Jiggle bones, collision traces, physics drops and ragdolls, and a weapon view whose RUI panels show the ammo counter all work as before.

The in-game tests found three runtime rules, now in the format notes:
- A model with a rig keeps no pose parameters, IK chains or nodes; otherwise R5R crashes playing blends or IK sequences.
- A rig lists its sequences in the engine's name order, which R5R needs to resolve autolayers.
- Rigs store a node transition table.

**Tests and package**

- 92 Python regressions and both CTest groups pass.
- The ZIP's examples compile and validate using only the packaged files and the Python standard library.

The ZIP contains the compiler, the Python tools (decompiler, reader, importer, round trip, packager and in-game harness), documentation and authored examples. The tools need Python 3.10+; the compiler runs on its own. No game assets are included: extract models from your own install. RPak packaging needs RePak and currently targets S3 / R5Reloaded only.

See [VALIDATION.md](https://github.com/taskinoz/r5-model-compiler/blob/v1.0.0/VALIDATION.md) for the evidence and its limits. It validates the tested corpora and representative in-game cases, not every possible source input. Later seasons are future targets.
